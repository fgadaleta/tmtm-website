# The Mythical Token-Month

Landing page for *The Mythical Token-Month*, by Francesco Gadaleta.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`. Plain HTML/CSS/JS, no build step, no dependencies.

## Structure

```
index.html      # landing page
excerpt.html    # free chapter excerpt
css/style.css
js/main.js
assets/
```
